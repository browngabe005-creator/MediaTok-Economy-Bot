# MediaTok Economy Bot

A standalone Discord.js collection and economy bot themed around MediaTok, spanning anime, manga, light novels, webnovels, movies, TV, games, and books. No NSFW/lolicon starter content.

## Setup

Requires Node.js 20.11+. Copy `.env.example` to `.env`, set your Discord bot `TOKEN`, `CLIENT_ID` and `GUILD_ID`, then run `npm install` and `npm start`.

**Never publish your `.env` or token.** Store bot data persistently in `data/store.json`.

Commands include `/roll`, `/claim`, `/daily`, `/balance`, `/collection`, `/wishlist`, `/trade`, `/sell`, `/profile`, `/leaderboard`, `/catalog`, `/shop`, and `/economyhelp`.
